1. ¿Qué ocurre cuando ejecutas node server.js?
El proceso se queda escuchando de forma activa en la terminal y se levanta un servidor local.

2. ¿Qué mensaje aparece en la terminal?
Aparece el texto: 'Servidor ejecutándose en puerto 3000'.

3. ¿Qué sucede cuando visitas la ruta /estado?
El servidor responde enviando un objeto en formato JSON con los datos del estado y el servicio:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
